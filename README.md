# Amora Acessórios

Vitrine digital e painel administrativo da Amora Acessórios (Timóteo - MG).

## Como rodar localmente

Certifique-se de ter o Node.js e o npm instalados e as variáveis de ambiente configuradas no arquivo `.env`.

```sh
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```

## Tecnologias

- React 19 + TypeScript
- TanStack Start / TanStack Router / TanStack Query
- Tailwind CSS
- Supabase (Auth, Database & Storage)
